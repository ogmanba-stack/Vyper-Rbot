Raid Bot
Un bot de Discord escrito en Python utilizando la librería discord.py.

Comandos
v nuke: Elimina todos los canales del servidor y crea uno nuevo.

v on: Crea múltiples canales y envía mensajes de spam.

# Configuración
1. Instala las dependencias:
pip install discord.py

2. Añade tu token de bot en la variable TOKEN del archivo.
